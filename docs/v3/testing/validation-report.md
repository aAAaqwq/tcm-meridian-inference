## 重要发现

### 1. 首测分数区间

根据后端真实运行数据验证：

```
实际可达: 70-89
PRD定义:  65-89

差异原因: 最大问题指数 = A(6) + B(12) + C(6) + D(4) + E(2.5) = 30.5
         需要 I > 32 才能进入 <71.4 分数段
         30.5 < 32，所以65-69区间理论上不可达
```

### 2. 复测分数区间

```
实际可达: 65-95
PRD定义:  65-95

验证通过: 使用天数加分(0-4) + 数据改善加分(0-3) 可突破首测限制
```

### 3. 封顶值验证

| 指数 | 封顶值 | 验证结果 |
|------|-------|---------|
| B(温差) | 12 | ✓ 验证通过 |
| D(趋势) | 4 | ✓ 验证通过 |

## 建议

如需使65-69区间在首测中可达，考虑以下方案：

### 方案1: 提高D指数封顶值
```python
D_cap = 6  # 从4提高到6
新最大问题指数 = 6 + 12 + 6 + 6 + 2.5 = 32.5 > 32 ✓
```

### 方案2: 添加新的扣分项F
```python
F = 2.0  # 例如：多经络严重低温
新最大问题指数 = 30.5 + 2.0 = 32.5 > 32 ✓
```

### 方案3: 调整分数映射阈值
```python
# 当前
if I > 32: score = 71.4 - 1.0 * (I - 32)

# 改为
if I > 28: score = 71.4 - 1.0 * (I - 28)  # 降低阈值
```
