# TCM v3 算法边界分析

> ⚠️ **已更新为新版算法（与PRD v1一致）**

## 问题指数理论最大值

根据PRD参数计算：

```
I = A + B + C + D + E

A (低温指数): 最大 8  (低温差距 > 3℃)
B (温差指数): 最大 16 (封顶)
C (偏侧指数): 最大 8  (6条经络同侧)
D (趋势指数): 最大 8  (封顶)
E (组合指数): 最大 7  (颈椎+腰椎+肝经最低)

理论最大值 = 8 + 16 + 8 + 8 + 7 = 47
```

## 分数映射区间分析（V3统一算法）

```
I <= 5:         score = 88 - 1.6*I
                → 80.0 ~ 88.0 (整体良好)

5 < I <= 12:    score = 80 - 0.71*(I-5)
                → 75.0 ~ 80.0 (轻度失衡)

12 < I <= 20:   score = 75 - 0.625*(I-12)
                → 70.0 ~ 75.0 (中度失衡)

20 < I <= 30:   score = 70 - 0.7*(I-20)
                → 63.0 ~ 70.0 (严重失衡)

I > 30:         score = 63
                → 最低分63
```

首测：clamp(score_raw, 63, 75)
复测：clamp(score_raw + test_bonus + improvement_bonus, 63, 88)

## 实际可达分数区间

由于理论最大 I = 47，所有分数区间均可达：

| 问题指数范围 | 计算分数 | 首测clamp后 | 症状等级 |
|-------------|---------|------------|----------|
| 0 ~ 5 | 88.0 ~ 80.0 | 75 ~ 75 | 整体良好(首测上限75) |
| 5 ~ 12 | 80.0 ~ 75.0 | 75 ~ 75 | 轻度失衡(首测上限75) |
| 12 ~ 20 | 75.0 ~ 70.0 | 70 ~ 75 | 中度失衡 |
| 20 ~ 30 | 70.0 ~ 63.0 | 63 ~ 70 | 严重失衡 |
| > 30 | 63 | 63 | 最低分 |

## 结论

**根据当前PRD参数，所有分数区间均可达：**

- 首测分数范围：63-75（受clamp限制）
- 复测分数范围：63-88（使用天数加分最高+8，改善加分最高+3）

各症状等级覆盖情况：
- 63-70分（严重失衡）：I > 20 即可达到，PI范围充足
- 70-75分（中度失衡）：12 < I <= 20
- 75-80分（轻度失衡）：5 < I <= 12（首测clamp到75，复测可达此区间）
- 80-88分（整体良好）：I <= 5（仅复测可达，首测clamp到75）

## 历史说明

本文档已更新为V3统一算法。旧版算法（90-0.4*I）的问题：
- 理论最大 I = 30.5
- 需要 I > 32 才能进入 <71.4 区间
- 导致 65-69 分数区间不可达

新算法（88-1.6*I）解决了此问题：
- 理论最大 I = 47
- I > 20 即可进入 63-70 严重失衡区间
- 所有分数区间均可达
