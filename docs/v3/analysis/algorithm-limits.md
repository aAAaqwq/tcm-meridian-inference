# TCM v3 算法边界分析

## 问题指数理论最大值

根据PRD参数计算：

```
I = A + B + C + D + E

A (低温指数): 最大 6  (低温差距 > 3℃)
B (温差指数): 最大 12 (封顶)
C (偏侧指数): 最大 6  (6条经络同侧)
D (趋势指数): 最大 4  (封顶)
E (组合指数): 最大 2.5 (颈椎或腰椎问题)

理论最大值 = 6 + 12 + 6 + 4 + 2.5 = 30.5
```

## 分数映射区间分析

```
I <= 10:        score = 90 - 0.4*I
                → 86.0 ~ 90.0

10 < I <= 22:   score = 86 - 0.55*(I-10)
                → 79.4 ~ 86.0

22 < I <= 32:   score = 79.4 - 0.8*(I-22)
                → 71.4 ~ 79.4

I > 32:         score = 71.4 - 1.0*(I-32)
                → < 71.4
```

## 实际可达分数区间

由于理论最大 I = 30.5，实际分数区间为：

| 问题指数范围 | 计算分数 | 首测clamp后 | 等级 |
|-------------|---------|------------|------|
| 0 ~ 10 | 90.0 ~ 86.0 | 89 ~ 89 | 健康优秀(上限89) |
| 10 ~ 22 | 86.0 ~ 79.4 | 80 ~ 86 | 轻度失衡 |
| 22 ~ 30.5 | 79.4 ~ 72.9 | 73 ~ 79 | 中度失衡 |
| > 32 | < 71.4 | 65 ~ 69 | 明显失衡(**不可达**) |

## 结论

**根据当前PRD参数设置，首测不可能达到65-69分区间。**

要达到65-69分，需要：
1. 提高B或D的封顶值，或
2. 添加更多的扣分项，或
3. 调整分数映射公式

## 建议

如果需要65-69区间可达，建议：

**方案1**: 提高D指数封顶值从4到6
```
新最大值 = 6 + 12 + 6 + 6 + 2.5 = 32.5
```

**方案2**: 添加新的扣分项F（例如：多经络严重低温）
```
新最大值 = 6 + 12 + 6 + 4 + 2.5 + F = 30.5 + F
需要 F > 1.5 才能使 I > 32
```

**方案3**: 调整分数映射公式，降低I>32的阈值
```
当前: I > 32 才进入 <71.4 区间
改为: I > 28 进入 <71.4 区间
```
